# Примеры фото

Четыре серии из личной коллекции Katherine Mironova: городские виды, цветы у набережной и парк.
Каждая серия содержит три разных кадра одного сюжета, снятых подряд.

Для публичного демо копии уменьшены до 1600 пикселей по длинной стороне и сохранены без EXIF,
включая геометки. Права на фотографии принадлежат автору.
